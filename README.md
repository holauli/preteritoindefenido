# Pretérito indefinido — тренажёр глаголов

Интерактивный тренажёр правильных и неправильных глаголов испанского языка в pretérito indefinido (EspañolPro).

- Фильтры по группам глаголов (правильные -ar / -er/-ir, орфографические изменения, i→y, e→i / o→u, сильные основы u / i / j, ser / ir / dar / ver) и по отдельным глаголам
- Выбор лиц (включая vosotros)
- 4 режима: писать, выбрать, карточки, таблица
- Повтор ошибок, справочник со спряжениями

Открыть: `index.html` (или через GitHub Pages).

Также в репозитории: `pretérito_perfecto_trainer.html`.
